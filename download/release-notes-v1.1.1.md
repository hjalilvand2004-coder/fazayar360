# ریلیز v1.1.1 — فضایار۳۶۰ (اصلاح بستهٔ پرتیبل ویندوز)

## چه چیزی در v1.1.0 خراب بود و چه شد؟ (گزارش صادقانه)

دو عیب در **فرایند ساختِ من** بود، نه در سیستم شما:

1. **`ModuleNotFoundError: No module named 'annotated_doc'`** — هنگام ساخت site-packages، به‌جای نصب «همهٔ» ۲۴ ویلِ دانلودشده، فقط ۱۴ بستهٔ صریح نصب شده بود؛ ماژول‌های `annotated_doc`، `pydantic_core`، `httpcore`، `python-dotenv`، `colorama` و ... جا مانده بودند و FastAPI در اولین import شکست می‌خورد.
2. **خطای `ي╗┐@echo`** — فایل `run.bat` با BOM یونیکد نوشته شده بود و cmd ویندوز خط اول را نمی‌شناخت (تنها ظاهری بود، اما ناخوشایند).

## اصلاحات v1.1.1

- site-packages با استخراج مستقیم «همهٔ» ویل‌ها بازسازی شد (۲۴ بسته، شامل فایل‌های کامپایل‌شدهٔ `win_amd64/.pyd`).
- **راستی‌آزمایی خودکار بسته‌بودن**: همهٔ `Requires-Dist` ها از METADATA هر بسته خوانده و با ارزیابی markerها برای محیط win/py3.12 کنترل می‌شود؛ اگر چیزی کم باشد، ساخت متوقف می‌شود (در اجرای واقعی، همین کنترل `exceptiongroup` را هم یافت و marker آن به‌درستی پردازش شد).
- اسکن `import` های کل کد بک‌اند در برابر site-packages به‌عنوان گام کیفیت.
- `run.bat`/`stop.bat` کاملاً ASCII بدون BOM + متغیرهای `PYTHONUTF8=1` و `PYTHONIOENCODING=utf-8`.
- pg_isready → createdb → uvicorn همان قبل (روی سیستم شما تا مرحلهٔ import آمده بود و PostgreSQL سالم بالا آمده بود).
